三步，模拟一个第三方系统

01

定义接口

选择 ERP 或 WMS 等第三方系统，配置请求方法和路径。支持 /orders/{orderId} 路径参数。

02

准备响应

粘贴第三方系统报文，或编写 main(request, mock) 函数动态生成返回内容。添加场景模拟成功、失败和异常。

03

调试与发布

输入请求参数验证返回结果，保存草稿并模拟发布。再切换到发布版本，体验草稿与发布的隔离。

这版原型的边界

无需账号，不连接数据库，不产生服务器 HTTP Mock 接口。配置保存在浏览器 localStorage，清理浏览器数据会清空配置。

支持单条件规则、原样文本、浏览器内脚本试运行和最长 3 秒延迟。脚本在受限浏览器工作线程中试运行，1 秒超时终止；这不是正式服务端脚本沙箱。

脚本工具：mock.uuid()、mock.now()、mock.randomInt(min, max)。脚本返回 { status, headers, body }。

Windows 域账号免密登录作为后续可选能力，第一版不加入账号与权限体系。
