# MockLab 交互原型

本原型供产品体验与审核使用，不包含正式后端或真实 HTTP Mock 接口

## 启动

在当前目录执行 `node serve.cjs`，浏览器访问 http://127.0.0.1:4173

无需安装任何依赖，也不访问 CDN 或其他公网资源

## 推荐体验

1. 打开 ERP 系统的「查询生产订单」，进入在线调试，依次使用 orderId 为 1001、1002 和 9999 的请求
2. 修改响应报文并保存草稿，分别调试「当前编辑内容」和「已模拟发布版本」，比较结果
3. 模拟发布，查看发布历史，再回滚到旧版本
4. 选择「查询物料信息」，体验 JavaScript 动态返回和路径参数
5. 添加自己的第三方系统、接口和响应场景

配置和最近 50 条调试日志保存在当前浏览器 localStorage；清除浏览器数据会移除这些内容

原型支持单条件规则，条件值按文本比较；暂不提供复杂条件树、自定义响应头表单、真实 HTTP 请求和用户体系

JavaScript 在 sandbox iframe 内的独立 Worker 中执行，限制网络访问，超时终止工作线程；这是本地交互验证方式，不能替代正式服务端隔离沙箱和内存配额

## 已调整的需求

- 独立单体项目，不依赖 pack-mom，不使用 PackCollectionUtils 或 EnableDto
- 使用 JDK、Spring 等现有能力，按需选择 Apache Commons 等公共依赖，具体组件和版本在正式开发时确认
- 首版不建设用户、角色和权限系统
- Windows 域账号免密登录为后续可选项，需 AD、浏览器及服务器的集成认证配置
- 正式功能开发与部署文档在原型审核通过后进行
